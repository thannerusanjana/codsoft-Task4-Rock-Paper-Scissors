# Rock-Paper-Scissors Game

##  Description
This is a fun Python game where the user plays Rock-Paper-Scissors against the computer. The computer randomly selects an option, and the winner is decided based on game rules.

##  Features
- Interactive gameplay
- Random computer choices
- Winner announcement
- Replay option

##  Technologies Used
- Python

##  How to Run
1. Open the project in Python IDLE
2. Run the `rock_paper_scissors.py` file
3. Enter rock, paper, or scissors to play
